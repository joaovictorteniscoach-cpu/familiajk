# Shorts para crianças — canal "Zuzu & Bibi"

Pacote de produção completo para YouTube Shorts infantis (pré-escolar, 2–6 anos),
feito para ser gerado com IA de vídeo e publicado em série.

Tudo aqui é **executável**: os roteiros já estão fechados por bloco de 10s, os
prompts de imagem e vídeo estão prontos para copiar, e os títulos/descrições/tags
já estão escritos.

## A ideia em uma frase

Um formato de **adivinhação com participação em voz alta**: a criança é
convidada a responder antes da revelação, e o final devolve uma pergunta nova —
o que faz o Short reiniciar sozinho na cabeça dela e no player.

## Ordem de trabalho

1. Travar a identidade visual (`02-biblia-visual.md`) — feito uma vez, serve para o canal inteiro.
2. Gerar o episódio (`03-producao.md` + o arquivo do episódio).
3. Gerar a capa (`capas/prompts-capas.md`).
4. Publicar com o pacote de SEO (`seo/`), marcando **"Feito para crianças"**.
