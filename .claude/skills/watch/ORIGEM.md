# Origem deste skill

Copiado de https://github.com/bradautomates/claude-video (pasta `skills/watch`),
versão 0.3.2 (commit 03ceb42), licença MIT (arquivo LICENSE ao lado).

Código conferido antes de entrar no repositório: só biblioteca padrão do Python;
fala com o YouTube (via yt-dlp) e, se configurado, com Gemini, Groq ou OpenAI.
Precisa de `ffmpeg` e `yt-dlp` (`pip install yt-dlp`).

Uso na academia: assistir vídeos de exercícios de tênis para o banco de
exercícios (app-exercicios) e analisar vídeos para as redes sociais.
